# Fair Variable Selection

Code for reproducing the results in the paper "Fair Variable Selection"

Notebooks:
- simulation_reg.ipynb : linear regression simulation
- simulation_class.ipynb : logistic regression simulation
- community_data.ipynb: results from the [Communities & Crime dataset](https://archive.ics.uci.edu/dataset/183/communities+and+crime)
- german_credit.ipynb: results from the [German Credit dataset](https://aif360.readthedocs.io/en/latest/modules/generated/aif360.datasets.GermanDataset.html)
